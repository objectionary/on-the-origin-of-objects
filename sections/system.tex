\section{System}\label{sec:system}

The \adeff{os} represents the name of the current operating system.

The \adeff{posix} object makes a Unix system call by name through the POSIX.
The \deff{win32} object makes a \ff{kernel32.dll} function call by name.
They both accept a \deff{tuple} of arguments.
The call returns an object whose \deff{code} attribute is the numeric
  return code of the syscall and whose \deff{output} attribute is its output.
For example, to get the identifier of the currently running process:

\begin{ffcode}
code. > pid
  posix
    "getpid"
    *
\end{ffcode}
