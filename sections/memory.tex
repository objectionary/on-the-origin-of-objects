\section{Memory}\label{sec:memory}

The \deff{malloc} object is an abstraction of a memory management system.
We use its \adeff{of} atom to allocate a \deff{chunk} of a given size.

The \deff{chunk} behaves like \deff{bytes}, but additionally has four atoms:

\begin{itemize}
  \adeff{size} to get the size of the chuck in bytes;
  \adeff{write} to write a few bytes;
  \adeff{read} to read a few bytes;
  \adeff{resized} to return a new chunk with same data but new size.
\end{itemize}

In this example, first, one kilobyte of memory with random data is allocated
  and represented by the \ff{cnk} object, a copy of \deff{chunk}.
Then, six bytes are written starting at the 200th byte.
Finally, a string is read back and \ff{"Hello!"} is printed:

\begin{ffcode}
malloc.of
  1024
  seq * > [cnk]
    cnk.write 200 "Hello!"
    stdout
      string
        cnk.read 200 6
\end{ffcode}
